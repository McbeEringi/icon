# icon

icon set of McbeEringi


run `bun build.mjs`

## main

![main grid view](src/img/icon.svg#$)
- `icon.svg#$`: grid view

- `icon.svg` `icon.png`: light
- `icon.svg#_` `icon_.png`: light transparent
- `icon.svg#!` `icon!.png`: dark
- `icon.svg#!_` `icon!_.png`: dark transparent



## variations

![var grid view](src/img/icon_var.svg)
- `icon_var.svg`: grid view

- `icon_var.svg#default`: main icon for reference
- `icon_var.svg#hat` `icon_hat.png`: with hat
